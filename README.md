# NSW Driver Licence – Support

This repository hosts the official support website for **NSW Driver Licence**, an iOS application developed by **Easy Learn**.

The website provides users with information about the app, technical support, and a way to report issues or submit feedback.

## About the App

NSW Driver Licence helps learners prepare for the New South Wales Driver Knowledge Test (DKT) through practice questions and simulated tests.
